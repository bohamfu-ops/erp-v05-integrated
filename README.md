# 光数外贸 ERP 演示 - 一体化版

全部功能整合在同一系统内，不依赖外部系统对接。

## 文件说明

- `index.html` - 完整演示（在线可直接打开）
- `外贸ERP演示_v0.5_一体化版_单文件.html` - 单文件版，可离线直接双击打开
- `1_shell.html` ~ `6_app.js` - 原始码分段，便于维护

## 演示内容

- 销售：客户、报价、合同（PI）、跟单看板、样品与借出、出运与单证、售后、业绩与提成
- 采购：物料需求与请购、采购单、供应商
- 仓库与品质：收货与检验、库存
- 生产：工单、委外加工、产品与 BOM
- 财务：应收与收款、应付与付款、汇率与结汇、出口退税、成本与利润、总账与关账
- 设定：审批、权限与日志、国家配置、上线迁移、单一窗口、客户门户

数据均为虚构的演示数据。
